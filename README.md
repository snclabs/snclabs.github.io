# SNC Labs

에스앤씨(SNC)의 회사 소개, SAP·웹 시스템 개발 및 운영, ESH 및 안전작업허가 관련 시스템 개발, GitHub 활동을 소개하는 정적 사이트입니다.

## 실행과 빌드

```sh
npm ci
npm run dev
npm run build
npm run preview
```

## GitHub Pages

공개 주소: [https://snclabs.github.io/](https://snclabs.github.io/)

`main` 브랜치에 변경 사항을 올리면 GitHub Actions가 사이트를 빌드하고 GitHub Pages에 배포합니다. 저장소의 Settings → Pages → Source는 **GitHub Actions**를 사용합니다.

## 디자인과 콘텐츠

- 배경은 화이트 `#ffffff`. 명함의 블루·네이비와 중립적인 회색만 사용합니다. 주요 색상은 `#216be4`, `#36a4ed`, `#21386d`, `#182334`입니다.
- 명함의 SNC 체크 심볼을 참고해 첫 화면용 블루 그래픽을 제작했습니다. 정식 로고 원본이 제공되면 워드마크를 교체할 수 있습니다.
- 한국어 Pretendard와 영문 Inter Tight를 사용하며, 외부 폰트가 로드되지 않으면 시스템 글꼴로 표시합니다.
- 특정 고객사 소개 및 사례 섹션을 제거했습니다. 회사 소개와 확인된 일반 업무 분야만 노출하며, 추가 업무의 상세 내용은 추후 받은 자료로 보완합니다.
- 실적 수치, 인증, 공식 파트너 지위를 임의로 추가하지 않습니다.
- 문의는 명함의 대표전화 `02-354-5001`로 연결합니다. 개인 휴대전화와 개인 이메일은 사용하지 않습니다.
- GitHub 공개 저장소가 있을 때 목록을 자동으로 불러옵니다. 공개 프로젝트가 없거나 API가 실패하면 기본 안내를 유지합니다.
- 모바일 메뉴, 키보드 사용 가능한 분야별 상세 설명, 모션 감소 설정을 지원합니다.

`artifacts/`의 작업용 파일과 로컬 캡처는 저장소와 배포에 포함하지 않습니다.
